# Acceptance checklist

The manual checks for MeowTab for Mac that CI cannot do. A tester with a real Mac works through the table below on a build from CI.

For each row, do what the Notes column says, then fill in Result:

- **Pass**: the scenario's expected outcome happened.
- **Fail**: it did not. Say what happened instead in Notes.
- **Not tested**: you did not check it. Say why in Notes. "Not tested" never counts as a pass.

| Spec | Scenario | Result | Notes |
|------|----------|--------|-------|
| fork-identity | About window | | Open About from the menubar. It shows MeowTab and its version. "Source code" opens github.com/tingtmu/mac_meowtab and "Based on AltTab" opens github.com/lwouis/alt-tab-macos. There is no Website link. |
| fork-identity | Supporting the author from the app | | In the About window, click "Sponsor AltTab's author". The browser opens github.com/sponsors/lwouis. |
| offline-app | Weeks after installing | | Use MeowTab for more than 14 days after installing it. To check sooner: quit MeowTab, run `defaults write io.github.tingtmu.meowtab.macos.license trialStartDate -float $(( $(date +%s) - 20 * 86400 ))` in Terminal, then open MeowTab again and use it for a while. No trial countdown, upgrade window or upgrade popover appears at any point. In Settings > Controls, add a second shortcut and open the switcher with it. Open the switcher and type: the search filters the windows. |
| offline-app | Settings window | | Open every section in the Settings sidebar (Appearance, Controls, General, Exceptions). The sidebar has no Upgrade entry, "Get Pro" or "Pro activated" button above Quit. Wherever a Pro badge appears, use the control next to it: in Appearance, pick the app-icon and title styles and Auto size; in Controls, add a second shortcut, set a shortcut's "After keys are released" to Search, and in "Shortcuts when active…" record the Search shortcut. Each choice applies, and nothing opens an upgrade or account view. |
| offline-app | No traffic after permissions | | CI only checks the phase before permissions. Grant Accessibility (and Screen Recording if you like), then use MeowTab for at least 2 minutes: open the switcher several times, open Settings and About. Meanwhile, in Terminal, run `lsof -nP -a -i -p $(pgrep -x MeowTab)` a few times, or `nettop -P -L 1 -p $(pgrep -x MeowTab)`. Neither shows a connection at any point. Clicking a link in About opens the browser; that traffic is the browser's, not MeowTab's. |
| fork-identity | Both apps installed | | Install AltTab next to MeowTab and run both. Change a setting in MeowTab, then open AltTab's Settings: the same setting is unchanged there. In System Settings > Privacy & Security > Accessibility, AltTab and MeowTab each have their own entry. |
| mood-peek | Picture placement | | Open 1, then 3, then 8 TextEdit windows, and open the switcher each time: a cat sits on the pane's top-left edge, the few cat with 1–2 windows, some with 3–7 and many with 8 or more. To look closely, run `screencapture -T 5 ~/Desktop/peek.png` in Terminal, open the switcher within 5 seconds and hold it until the shot is taken, then zoom in. The cat is cut off exactly at the pane's top edge: no gap between them, and no part of the cat drawn over the pane. The picture starts 24 pt in from the pane's left edge; the cats have a little transparent margin, so their first visible pixels are about 28 pt in (few and some) or 30 pt (many), about 56 or 60 px on a Retina screenshot. The cat's top stays at least 12 pt below the menu bar. Repeat with each style in Settings > Appearance (thumbnails, app icons and titles). |
| mood-peek | Scrolled grid with placeholders | | Keep `log stream --level debug --predicate 'category == "peek"'` running in Terminal. Open real windows until the switcher's grid has to scroll (about 15 to 20 on a laptop), and close every window of two other running apps, for example Preview and Safari, so they show as windowless tiles at the end. Open the switcher and scroll. The log's `n=` equals the number of real windows: scrolled-out tiles count, and the two windowless tiles don't. Then, in an app with exactly two windows open, choose Window > Merge All Windows and open the switcher again: `n=` drops by one, since a group of tabs counts once. |
| mood-peek | Typing a search | | With the log running and about 10 windows open (the many cat), open the switcher and type a few letters that match only one or two windows. The tiles narrow, but the cat stays the many cat at the same height on the pane's top-left edge, and the log's `n=` stays the same. |
| mood-peek | A window closes while the switcher is open | | Open 3 windows (the some cat). Open the switcher, keep holding the shortcut, select one of the windows and press W (Close window), or click the close button on its tile. The cat changes to few at once and sits on the pane's new top edge, with no gap or overlap, and no part of it goes above the usable area. Do the same with 8 windows (many): after the close, the some cat shows. |
| mood-peek | Cancel and reopen quickly | | In Settings > Appearance > Animations…, turn on "Fade out animation of Switcher". With 3 windows open, open the switcher, press Esc, and reopen it at once, while the pane is still fading. The cat disappears the moment you press Esc, without waiting for the fade; the reopened switcher shows its own cat on its pane's edge, and no old picture is left anywhere. Repeat a few times, then once more with the fade turned off. |
| mood-peek | Clicking where the picture is | | With a window behind where the cat appears, open the switcher and click on the cat. The click does what a click on any spot outside the pane does: the switcher closes without switching. The cat never takes the click: the window behind it doesn't come forward, and MeowTab doesn't become the active app. |
| mood-peek | VoiceOver | | Turn on VoiceOver (⌘F5). Open the switcher and move through it with the arrow keys and with VoiceOver's own keys (Control-Option and the arrows). VoiceOver reads the tiles and never lands on or announces the cat, and no tile in the switcher is the cat itself. Turn VoiceOver off afterwards (⌘F5). |
| mood-peek | Two displays with different scales | | Connect a non-Retina display next to a Retina one, and set Settings > Appearance > "Show on" to "Screen including mouse". Open the switcher with the pointer on each display in turn. Each time the cat is sharp, with a smooth outline and no blur, and sits on that pane's top-left edge with no gap or overlap. Without a non-Retina display, mark this row Not tested. |
| mood-peek | Fullscreen Space | | Put an app into full screen (the green button) and open the switcher from its Space. The cat shows on the pane's top edge there and disappears with the pane. Switch to another Space and back: no picture is left behind on any Space. |
| mood-peek | Measuring on a real Mac | | In Terminal, run `log stream --level debug --predicate 'category == "peek"'`. With about 10 windows open, open the switcher 20 times, releasing it or pressing Esc each time. Each opening logs at least one line `update <ms> ms n=<n>`, where n is the number of windows. Add the median and the maximum of the times to these notes: the median is at most 1 ms. |
| mood-peek | Summon with another shortcut | | In Settings > Controls, add a second shortcut that uses the same hold key with another key, for example Option and the backtick. In Settings > Appearance > Animations…, set "Apparition delay of Switcher" to 900 ms so the switch is easy to watch. Open the switcher with the first shortcut and, still holding Option, press the second shortcut's key. While the pane is hidden for the rebuild, the cat is hidden too: it is never on screen without the pane under it. Then it comes back on the new pane's edge. Set the delay back to 100 ms afterwards. |
| mood-peek | Search hint and the peek | | The search hint shows at most 3 times, 72 hours apart, and never after the first search, so reset it first: quit MeowTab, run `defaults delete io.github.tingtmu.meowtab.macos.usage searches; defaults delete io.github.tingtmu.meowtab.macos searchDiscovery.exposures; defaults delete io.github.tingtmu.meowtab.macos searchDiscovery.lastExposure; defaults delete io.github.tingtmu.meowtab.macos searchDiscovery.hasSearched` in Terminal (a "does not exist" message is fine), and open MeowTab again. In Settings > Controls > Shortcuts when active…, check that "Show the search hint" is on. Open 8 or more windows, then open the switcher and hold it for 2 seconds without moving the selection. The hint, "Press S to search your windows.", appears below the pane, not over the cat. On a pane wide enough that the hint can't touch the cat, it may stay above. |
